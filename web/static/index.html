Pick a primary model — without one, agents have nothing to call.

Model routing (optional)

Override which model each individual agent uses, and tune its max tokens and temperature. Leave a field blank to inherit the primary or light default from above. Higher temperature (up to 2.0) produces more varied output; lower (0.0) is more deterministic. Max tokens controls how long each agent's response can be — higher values allow more detailed reasoning but cost more. You can change these mid-run at any break point.

Sources (optional)

Pick which academic sources this run will query. Each source is an API — OpenAlex, arXiv, PubMed, etc. Uncheck a source to skip it entirely for this run. Sources that require an API key (Scopus, CORE, Semantic Scholar, etc.) will be shown but silently skipped at run time if no key is provided — add one in the Source API keys section below or in your .env file. The default limit of 8 results per source keeps runs fast; increase it for broader coverage.

Source API keys (optional)

Store a per-user API key for sources that require authentication (Scopus, CORE, Semantic Scholar, etc.). These are stored encrypted in the database and used instead of the matching .env variable for your runs. Keys are per-user — each researcher can use their own credentials. Get a key from the source's developer portal (e.g. dev.elsevier.com for Scopus, core.ac.uk/services/api for CORE).

Compare to previous run (optional)

Select a previous run to compare against. Sources already found in that run are flagged as "previously seen" in the Understanding Map, so you can see what's new since your last pass at this topic. Useful for tracking how the literature evolves between runs, or for resuming a broad survey without re-reading the same papers. Leave as "None" for a fresh start.

Excluded sources (optional)

Sources you mark here are never inserted into your runs — useful for retracted papers, predatory journals, or authors whose work you don't want cited. Matches are case-insensitive and work by: DOI (exact, e.g. 10.1234/abc), URL (substring, e.g. predatory-journal.com), or title substring (e.g. "predatory journal"). Exclusions persist across all your future runs until removed.
